# 📘 Meu Guia Definitivo de Git & GitHub

Este repositório serve como um manual de consulta rápida para comandos, rotinas e boas práticas de controle de versão.

---

## 💼 Resumo de Bolso para o Dia a Dia

Imagine o fluxo do Git como o processo de organizar e enviar um relatório oficial:

* **`git pull origin main`** 🔄 *(Olhar a mesa de trabalho)*
  > Você puxa as atualizações da nuvem para garantir que ninguém mexeu no arquivo enquanto você estava fora. Evita conflitos.
  
* **`git status`** 🔍 *(Revisar a pasta)*
  > Você olha o que mudou na sua máquina. Arquivos novos ou modificados aparecem em vermelho.
  
* **`git add .`** ➕ *(Colocar no envelope)*
  > Você junta todas as alterações que fez e as coloca prontas dentro do envelope de envio.
  
* **`git commit -m "mensagem"`** 💾 *(Carimbar e datar)*
  > Você fecha o envelope e escreve uma etiqueta clara por fora dizendo exatamente o que foi feito ali dentro.
  
* **`git push origin main`** 🚀 *(Enviar pelo correio)*
  > Você despacha o envelope fechado direto para a nuvem do GitHub para o servidor atualizar.

---

## 🛠️ Comandos Extras Importantes

* `git log` 📜 Mostra o histórico de todos os commits realizados no projeto.
* `git config user.email` 📧 Verifica qual conta está ativa na pasta atual.
